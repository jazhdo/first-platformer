# First Platformer

> This is a basic platformer game where you go through numerous levels until you pass the last one to beat the game.

## How to play
> Press play, use w-a-d (without s) to move or use the arrow keys. Then just keep going right until you get to the final level
> Press the gear icon on the top right corner to go back to the menu screen.
